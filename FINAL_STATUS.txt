================================================================================
LESSONS LEARNED & BEST PRACTICES
================================================================================

1. Cross-file contracts are critical
   → One layer injects defaults → entire system corrupted
   → Solution: Single source of truth

2. "or" operator is dangerous for sensors
   → value = data.get("x") or 0 coerces valid 0 to default
   → Solution: Explicit null checks, preserve 0

3. Freshness is invisible until missing
   → Users assume "latest" is real-time
   → Solution: Always include age_seconds + status

4. Device metadata trust is earned
   → Hardcoded values erode farmer confidence
   → Solution: Only report what's actually measured

5. Multiple telemetry paths = multiple bugs
   → Different validation logic, different defaults
   → Solution: Single canonical endpoint

6. Synthetic data leaks through system
   → Default injected in one layer
   → Assumed real in downstream
   → Used in ML predictions
   → Affects farmer decisions
   → Solution: Strict validation at entry point
